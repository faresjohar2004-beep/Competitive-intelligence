WHAT ASTRA OS ACTUALLY IS
A daily identity-transformation habit app (web SPA + Expo mobile) built on a promise -> actions -> AI-missions -> reflection loop, with five tracked life scores, server-enforced streaks + a monthly freeze, unlockable chapters, and AI-framed identity artifacts (coach, letters, biography), monetized via a Stripe "Pro" tier that is fully wired on web and entirely absent on mobile.

CURRENT USER JOURNEY
Web: Landing -> 3-step card onboarding -> Dashboard daily ritual -> broad secondary exploration (12 pages). Mobile: email/password sign-in -> 3-step free-text onboarding -> 5 tabs (Dashboard/Actions/Missions/Coach/Profile), with 8 web surfaces absent and the Dashboard read-only (Actions is the only logging screen).

STRONGEST FEATURES
The real core loop (score math, streak state machine, promise reconciliation on web); a genuinely context-aware Coach, re-verified this run to inject 4 live data sources into a real gpt-4o-mini call (coaching.ts:13-80); server-enforced streak freeze; idempotent account deletion on both platforms; a unit-tested server-side push pipeline; and a clean core auth model with no IDOR/mass-assignment observed and properly role-gated admin routes.

WEAKEST FEATURES
Web Settings "Save Changes" is inert, re-verified this run with a full file read (Settings.tsx — unbound name input, no onClick on the button). Future-Self Projection, Letters, and Biography are marketed as AI but contain zero AI calls, re-verified this run (letters.ts:41, ai.ts:89,92,228,250,261, timeline.ts:15-48). Life Map history and initial onboarding scores fabricate data via Math.random(), re-verified this run (lifeMap.ts:32, users.ts:72,101). Admin metrics hardcode impact totals to 0, re-verified (admin.ts:57-58). One dead nav link (/trajectory) confirmed 404 this run.

FUNCTIONAL VS PARTIAL FEATURES

Partial/fabricated: Future-Self Projection (no AI), Life Map (random), Timeline (stubbed arithmetic), Letters/Biography (templated), admin metrics (hardcoded 0), mobile action logging (no mission reconciliation — re-verified zero completeMission calls this run), the entire mobile monetization layer (absent), mobile push delivery (broken projectId, re-verified this run).
